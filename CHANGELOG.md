# Changelog

## 1.1.0

- Added the English version, installable from **Mods > Install from file...**
- Grey stick icons show the tilted DualSense stick, L or R with arrows, instead of L3 and R3. The game uses them for tilting the stick.
- The PT-BR version installs with `Instalar.bat`. The installer finds the data folder, backs up the fonts and checks SHA-256.

## 1.0.0

- First PT-BR version: Cross, Circle, Square, Triangle, L1, R1, L2 and R2 in both fonts.
